Nexo DNS combines the original PrivateDNSAndroid hostname list, Quick Settings and Shizuku support with a four-tab native management interface inspired by ADNS.

DNS: manage and reorder private DNS hostnames.
Statistics: read provider traffic and available account quotas.
Queries: inspect recent requests with local search and filters.
Settings: connect official NextDNS/AdGuard DNS APIs or attach any HTTPS provider dashboard through Custom Tabs or optional WebView.

API access is read-only. There is no automatic DNS switching or remote API mutation. API keys use Android Keystore encryption. Web-panel passwords are not intercepted. Android 9+.

This is an alpha build. Device validation and real-account integration testing remain pending. MIT-licensed fork; see the repository for provenance, security documentation and regression tests.
